# Инструкция по запуску на HeavenCloud

В разделе **Variables** укажите следующие настройки:
- **USER UPLOADED FILES**: True
- **AUTO UPDATE**: False
- **APP PY FILE**: bot.py
- **REQUIREMENTS FILE**: requirements.txt
- Остальные поля (GIT REPO, BRANCH, ACCESS TOKEN и т.д.) оставьте пустыми!

**Шаги для запуска:**
1. Зайдите в раздел **Files** на панели.
2. Загрузите туда все `.py` файлы, `requirements.txt` и `.env`.
3. Откройте `.env` и впишите свои данные (DISCORD_TOKEN, GEMINI_API_KEY, ADMIN_ID).
4. Нажмите **Start** в консоли.
