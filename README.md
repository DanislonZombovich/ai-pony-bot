## 🔬 Обзор проекта

Данный проект — это полнофункциональный автономный агент для Discord, построенный на новейшем Google GenAI SDK (`google-genai` v1) с поддержкой современной быстрой языковой модели **Gemini 3.5 Flash Lite** и бессерверной облачной базы данных **Neon PostgreSQL**.

Бот объединяет естественный разговорный интерфейс (NLP) с возможностями активного воздействия на среду (Agentic Tool Calling):
- Анализ текста, документов, изображений, аудио и видеофайлов.
- Понимание неструктурированных команд с опечатками ("заглуши до вечера", "поставь трек", "зайди в голосовой").
- Управление сервером (таймауты, блокировки, выдача/снятие ролей) через нативные вызовы функций Gemini.
- Долговременная сессионная память каналов с эффективной индексацией в PostgreSQL.
- Интеграция с голосовыми каналами и YouTube-аудио.

## 📊 Data Science & AI Agents Фокус

### 1. Контекстное окно и менеджмент сессионной памяти
- В LLM-системах стоимость инференса и время задержки (TTFT — Time To First Token) напрямую зависят от размера контекста.
- Бот реализует скользящее окно истории (Sliding Context Window): вместо бесконечного накопления сообщений извлекаются последние $K$ реплик ($K=40$ по умолчанию) с хронологической сортировкой.
- Составной индекс в PostgreSQL `(channel_id, timestamp DESC)` гарантирует выборку контекста за доли миллисекунды без просадки производительности при росте базы до сотен тысяч сообщений.

### 2. Семантический роутинг и Tool Calling (Function Calling)
- Вместо жесткого сопоставления по регулярным выражениям или громоздких деревьев `if/else` бот использует нативный Function Calling (декларативные схемы `tools` в Gemini API).
- Модель автоматически распознает намерение пользователя (Intent Recognition) из разговорной речи, извлекает сущности (Entity Extraction: имя пользователя, длительность бана, название аудиодорожки) и формирует вызов соответствующей функции.
- Исполнение критических операций защищено верификацией прав на уровне Python (`ADMIN_ID`), исключая атаки с подменой контекста (Prompt Injection).

### 3. Мультимодальная токенизация и обработка вложений
- **Изображения и документы**: Кодируются в base64 / бинарные байты (`types.Part.from_bytes`) с сохранением исходного MIME-типа.
- **Аудио и видео высокого разрешения**: Автоматически загружаются через асинхронный клиент `client.aio.files.upload` в Google File API, что снимает ограничения на объем оперативной памяти и позволяет модели воспринимать мультимодальные таймлайны.

### 4. Каскадная оркестрация моделей (Cascade Fallback Orchestration)
- Архитектура устойчива к исчерпанию RPM/TPM квот и сбоям апстрим-серверов:
  $$\text{gemini-3.5-flash-lite} \xrightarrow{\text{fallback}} \text{gemini-3.5-flash} \xrightarrow{\text{fallback}} \text{gemini-3.1-flash-lite} \xrightarrow{\text{fallback}} \text{gemini-2.5-flash}$$
- Цикл перебора перехватывает исключения API (включая HTTP 503 Service Unavailable, 429 Rate Limit) и бесшовно передает запрос следующей модели, сохраняя сессию пользователя.

### 5. Асинхронная персистентность состояния в Neon Serverless DB
- Построен на асинхронном драйвере `asyncpg` с пулом соединений (Connection Pooling).
- Если база данных временно недоступна, архитектура переключается на локальный `in-memory fallback`, гарантируя доступность бота 24/7 (Graceful Degradation).

## ⚙️ Настройка параметров в коде (`bot_settings.py`)

Все параметры поведения вынесены в чистый файл конфигурации `bot_settings.py`. Вы можете безопасно менять их под свои задачи:

### 1. Степень креативности (`TEMPERATURE`)
```python
TEMPERATURE = 1.2
```
- **`0.0 - 0.5`**: Детерминированные, строгие и формальные ответы. Минимальный риск галлюцинаций.
- **`0.7 - 1.0`**: Сбалансированный диалоговый режим (подходит для большинства ассистентов).
- **`1.1 - 1.5`**: Повышенная фантазия, яркие эмоциональные окраски, свободный юмор (установлено по умолчанию).

### 2. Основная модель (`TEXT_MODEL`)
```python
TEXT_MODEL = "gemini-3.5-flash-lite"
```
- Флагманская сверхбыстрая модель `gemini-3.5-flash-lite` обеспечивает минимальный TTFT и идеальна для чат-ботов с высокой частотой сообщений.

### 3. Резервная лестница моделей (`FALLBACK_MODELS`)
```python
FALLBACK_MODELS = [
    "gemini-3.5-flash",
    "gemini-3.1-flash-lite",
    "gemini-2.5-flash",
]
```
- Порядок моделей, используемых в случае недоступности или исчерпания лимитов основной модели.

### 4. Глубина контекстной памяти (`CONTEXT_LIMIT`)
```python
CONTEXT_LIMIT = 40
```
- Количество сообщений, удерживаемых в контексте канала. Увеличение до 60–100 позволяет боту помнить глубокие нити разговора, но расходует больше токенов за запрос.

### 5. Системная инструкция (`SYSTEM_INSTRUCTION`)
- Определяет характер, стиль общения, правила поведения и реакцию на команды.
- Текущая конфигурация задает постироничный, энергичный образ без цензуры с обязательным триггером `join_voice` при приглашении в войс. Вы можете изменить ее на образ бизнес-консультанта, игрового компаньона или модератора.

## 🚀 Инструкция по установке и запуску

### Требования
- Python 3.10+
- Установленный `ffmpeg` в системе (для воспроизведения аудио в Discord)

### Создание Discord-приложения и получение токенов
1. Перейдите на [Discord Developer Portal](https://discord.com/developers/applications).
2. Создайте приложение, перейдите в раздел **Bot**, создайте бота и скопируйте токен.
3. Включите все **Privileged Gateway Intents**:
   - `Message Content Intent`
   - `Server Members Intent`
   - `Presence Intent`
4. В разделе **OAuth2** -> **URL Generator** выберите `bot` и `administrator` (или права на отправку сообщений, подключение к войсу и управление участниками), перейдите по сгенерированной ссылке и добавьте бота на свой сервер.
5. Получите бесплатный API ключ в [Google AI Studio](https://aistudio.google.com/).

### Локальный запуск
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/DanislonZombovich/ai-pony-bot.git
   cd ai-pony-bot
   ```
2. Создайте виртуальное окружение:
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```
3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Настройте файл `.env` (скопируйте из шаблона `cp .env.example .env`):
   ```ini
   DISCORD_TOKEN="ваш_токен_discord"
   GEMINI_API_KEY="ваш_ключ_google_api"
   ADMIN_ID="ваш_discord_user_id"
   DATABASE_URL="postgresql://neondb_owner:password@ep-xyz.eu-central-1.aws.neon.tech/discord_bot_db?sslmode=require"
   ```

| Переменная | Обязательная | Назначение / Описание | Пример / По умолчанию |
| :--- | :---: | :--- | :--- |
| `DISCORD_TOKEN` | Да | Токен Discord-бота из Discord Developer Portal (Bot -> Token). | `MTA5...` |
| `GEMINI_API_KEY` (или `GOOGLE_API_KEY`) | Да | API-ключ Google Gemini из Google AI Studio для инференса LLM. | `AIzaSy...` |
| `ADMIN_ID` | Да (для админ-действий) | Числовой Discord User ID владельца бота для доступа к модерации и опасным вызовам функций. | `123456789012345678` |
| `DATABASE_URL` (или `AIVEN_URI`) | Нет (Опционально) | Строка подключения к PostgreSQL (Neon Serverless). При отсутствии активируется безопасный in-memory fallback. | `postgresql://user:pass@ep-xyz.neon.tech/db?sslmode=require` |
| `TEMPERATURE` *(в `bot_settings.py`)* | Настройка | Температура генерации ответов модели от `0.0` (сухой ответ) до `1.5` (креативный/юмор). | `1.2` |
| `TEXT_MODEL` *(в `bot_settings.py`)* | Настройка | Основная языковая модель для генерации диалогов и вызова функций. | `"gemini-3.5-flash-lite"` |
| `CONTEXT_LIMIT` *(в `bot_settings.py`)* | Настройка | Максимальное количество последних сообщений контекста, извлекаемых из истории канала. | `40` |

5. Запустите бота:
   ```bash
   python bot.py
   ```

### Развертывание на хостинге (Discloud / Linux VPS)
Проект содержит готовый файл `discloud.config`:
```ini
ID=aiponybot
TYPE=bot
MAIN=bot.py
NAME=AIPonyBot
RAM=512
AUTORESTART=true
VERSION=latest
APT=ffmpeg
```
Загрузите архив с проектом в панель управления [Discloud](https://discloudbot.com/) и добавьте переменные окружения в настройках бота.
